# 💖 Hiệu Ứng Trái Tim Đập - Ngọc Châm

Dự án chuyển đổi chính xác **100% logic thuật toán và hạt** từ file Python Tkinter (`heartpython.py`) sang chuẩn web **HTML5 Canvas & JavaScript thuần**.

---

## 🌟 Tính Năng Nổi Bật

- **Bảo toàn 100% logic code**: Phương trình tọa độ trái tim parametric, thuật toán tán xạ hạt bên trong (`scatter_inside`), co giãn hào quang viền (`shrink`), đường cong co bóp nhịp đập (`curve`), và tham số lực biến dạng ma thuật (`0.520`).
- **Tốc độ chuẩn**: Giữ nguyên chu kỳ nhịp đập 160ms/frame (~20 frame) của Tkinter gốc.
- **Tương thích hoàn hảo mọi thiết bị**: Tự động căn giữa màn hình và co giãn mượt mà trên cả PC, Tablet lẫn Smartphone (màn hình dọc/ngang).
- **Chữ ở giữa trái tim**: Đã gắn sẵn chữ **Ngọc Châm** phát sáng ở tâm trái tim, bỏ toàn bộ chức năng click đúp theo yêu cầu.

---

## 🚀 Hướng Dẫn Deploy Lên Netlify

### Cách nhanh nhất: Netlify Drop (Chỉ 10 giây) ⭐ Khuyên dùng

1. Truy cập vào trang: [https://app.netlify.com/drop](https://app.netlify.com/drop) (đăng nhập tài khoản Netlify của bạn).
2. Kéo thả toàn bộ thư mục **`traitim`** vào khung tải lên của Netlify.
3. Đợi vài giây, Netlify sẽ tạo ngay cho bạn một đường link web trực tiếp (ví dụ: `https://ten-ngau-nhien.netlify.app`).
4. Bạn có thể vào mục **Site configuration > Change site name** để đổi tên link theo ý thích (ví dụ: `https://ngoc-cham.netlify.app`).
